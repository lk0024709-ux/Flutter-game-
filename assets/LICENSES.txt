Blade Brawl: Rannbhoomi - third-party asset credits
===================================================

AUTOMATIC. Every file listed here was downloaded by scripts/download_assets.sh
either from GitHub (the mirror below) or, when you run the script on your own
machine, from the original CC0 sources. Re-running the script appends new lines
at the bottom - never delete a line, the CC-BY entries are a licence condition.


WHY ONLY GITHUB MIRRORS ARE PRESENT IN THIS CHECKOUT
----------------------------------------------------
The build sandbox used to assemble this repository can only reach
github.com / api.github.com / codeload.github.com. kenney.nl, quaternius.com,
poly.pizza, ambientcg.com, freesound.org, opengameart.org and
raw.githubusercontent.com are all unreachable from it, so the assets they host
could not be fetched. The download script in scripts/ contains the full list of
original sources with fallbacks - run it locally (./scripts/download_assets.sh)
and the game picks the extra files up automatically, because every asset folder
is already declared in pubspec.yaml.

WHAT scripts/download_assets.sh ADDS ON TOP OF THE ABOVE
--------------------------------------------------------
The script is idempotent and appends a licence line for every file it
fetches. It looks for the remaining Kenney kits (mini-dungeon,
mini-characters, nature), extra ambientCG surfaces and the full Kenney
Impact Sounds / Music Jingles packs straight from the original hosts.
Nothing it fetches is required: the game already renders with what is
committed here, missing models fall back to procedural geometry and
missing textures fall back to the palette in lib/theme/app_colors.dart.

# Blade Brawl: Rannbhoomi

Premium earthy-toned Flutter + Flame top-down arena RPG.

## Run locally
```bash
flutter pub get
flutter run
```

## Phase 1 foundation
- Persistent 3×3 Forge grid with six weapon tiers, merge rules, auto-forging and offline catch-up.
- Campaign rank/map overview with 350 level tiles.
- Flame arena prototype with movement, directional melee attacks, health bars and nearest-enemy free-for-all AI.
- Armory purchase UI and coin balance.
- GitHub Actions workflow for formatting, analysis, tests and a release APK artifact.

## Roadmap
1. Core app and playable arena foundation.
2. Creature-specific abilities and battle result grades.
3. Level progression, armor effects, boosters, map twists, storm ring and healing shrines.
4. Campaign bosses and seven Elite Chimera encounters.
5. Balance, performance tuning and device testing.

This is a phased playable foundation; advanced systems from the master design brief are not all implemented yet.
